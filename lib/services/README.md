# Các dịch vụ của ứng dụng

Đây là lớp trung gian giữa màn hình và Firebase/API.

| Thư mục | Dùng khi cần sửa |
| --- | --- |
| `ket_noi_api` | Gọi Cloud Functions/API bài thi và tài khoản |
| `tai_khoan` | Đăng nhập, đăng xuất, phiên tài khoản |
| `du_lieu` | Đọc/ghi Firestore và xóa dữ liệu theo lô |
| `nghiep_vu` | Tiến độ học, tin tức, banner |
| `tep` | Upload ảnh, đọc Excel, chọn file |

Import trực tiếp file từ thư mục tương ứng; các đường dẫn chuyển tiếp cũ đã được bỏ.
